# Village Spawn

Every time you make a new world, you start standing in a village. It feels like
spawning into a busy server lobby, with villagers and houses all around you.

Works in single player and on servers. Fabric only.

## Minecraft versions

| version | Java |
|---|---|
| 1.21.11 | 21 |
| 26.2 | 25 |

## Building

```bash
./gradlew "Set active project to 1.21.11-fabric"
./gradlew "1.21.11-fabric:build"
```

The jar lands in `versions/1.21.11-fabric/build/libs/`.
